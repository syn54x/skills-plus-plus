`auto-grill` draws each choice so it reads on a narrow screen. Every Escalation and Challenge now opens with the question in one plain sentence, then stacks its options under `A:` and `B:` labels within 72 columns, with the Best fit marked and only names you already know. Before this, options sat side by side in columns over 100 characters wide, which wrapped in the desktop app and buried the deciding difference. In the Claude desktop app, where an inline visual tool is available, each choice is drawn as rendered cards, grids or timelines, with a button per option that sends your answer.
