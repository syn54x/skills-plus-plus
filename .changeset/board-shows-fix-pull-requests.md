The epic board now lists an Epic's fix pull requests in a `Fixes` group after the Waves: one row per open or merged fix with a `fix open` or `fix merged` chip, its number, the Sub-issue its `Refs` line names (or `unattributed`) and a `PR` button that copies its link. While any fix is open, the board header and the status line end with the count, as in `12/12 merged · 3 fixes open`. A failing pull request read keeps the ticket rows and shows its error. A board stored by an earlier version is dropped and redrawn on the next refresh.
