# Credits

`diagnosing-bugs` is a rewrite of Matt Pocock's [`diagnosing-bugs`](https://github.com/mattpocock/skills/tree/main/skills/engineering/diagnosing-bugs). It keeps the order of work: redact secrets before showing output, build a feedback loop that goes red, shrink the case, find the cause by hypothesis and instrumentation, then lock the fix in with a test.

spp took the idea, not the text: the wording is spp's own.
