# Credits

`harden` draws on Jesse Vincent's Superpowers [`writing-plans`](https://github.com/obra/superpowers/tree/main/skills/writing-plans): a plan written for a worker who has seen neither the codebase nor the spec, with exact file paths as Create, Modify and Test lines, the interfaces each task produces and consumes, and no placeholders such as "TBD" or "add appropriate validation". `harden` applies that to one GitHub issue as its Ticket contract.
