# Credits

`tdd` is a rewrite of Matt Pocock's [`tdd`](https://github.com/mattpocock/skills/tree/main/skills/engineering/tdd). It keeps agreeing the seams where tests go before writing them, the red-green loop, the anti-patterns to avoid, and a reference file of example tests.

spp took the idea, not the text: the wording is spp's own.
