# Credits

`implement-issue` draws on two sources.

- Matt Pocock's [`implement`](https://github.com/mattpocock/skills/tree/main/skills/engineering/implement): build one ticket through `tdd` at agreed seams, type-check and run the current test file often, and leave the review to someone else.
- Jesse Vincent's Superpowers [`subagent-driven-development`](https://github.com/obra/superpowers/tree/main/skills/subagent-driven-development): the worker as a fresh subagent with one task, a self-review before handing back, and the four report statuses (DONE, DONE_WITH_CONCERNS, BLOCKED, NEEDS_CONTEXT).

spp took the ideas, not the text: the wording is spp's own.
